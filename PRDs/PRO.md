产品需求文档 (PRD): CET-TransMaster

## 1. 项目概览

一个为中文使用者设计的四六级中译英训练网页应用。核心价值在于：逐句高压训练 + 实时计时 + 多模型 AI 深度纠错。

## 2. 核心功能模块

### A. 配置管理 (Settings)

- 多模型集成： 支持 OpenAI, DeepSeek, Google Gemini, 智谱 AI (Zhipu), Minimax, 阿里 Qwen, Anthropic, Ollama, 自定义 API
- 自定义配置： 用户可输入对应平台的 API Key，选择模型 ID（如 gpt-4o, deepseek-chat 等），并设置自定义 API Base URL
- 本地存储： 所有 Key 仅保存在浏览器 localStorage 中，确保隐私

### B. 文段准备与智能拆分 (Input & Splitting)

- 内容输入： 提供两个文本框：中文原文（必填）、参考译文（选填）
- 自动拆分： 程序默认根据中文标点（。？！）进行初步拆分
- 手动微调： 拆分后以"卡片列表"形式展示每一句。用户可以：
  - 合并相邻的两句
  - 在任意位置再次切分
  - 直接编辑拆分后的文本内容
- **重要**：参考译文作为整体保存，不进行拆分，仅用于 AI 对比分析

### C. 沉浸式翻译练习 (Training Mode)

- 实时计时： 点击"开始"后，秒表启动，实时显示已用时间
- 逐句聚焦： 界面上方显示当前中文句子，下方为英文输入框
- 原文高亮： 原文预览区高亮显示当前正在翻译的句子
- 回车流转： 用户输入完一句按 Enter，自动保存并切换至下一句，直到全部完成
- 进度感知： 侧边或顶部显示进度条（例如：3/8 句）
- 布局切换： 支持左右布局（PC端）和上下布局（移动端）

### D. AI 深度分析 (AI Review)

- **分析逻辑**：
  - 用户翻译完成所有句子后，将用户译文整合为完整文本
  - 整体与参考译文（或 AI 生成的译文）进行对比分析
  - 分析完成后，逐句呈现分析结果给用户
- **反馈维度**：
  1. 错误诊断：拼写、时态、介词误用
  2. 地道表达：提供更符合四六级高分标准的替代词汇
  3. 综合打分：基于准确度、流利度、词汇多样性给出百分制分数
  4. 逐句分析：包含原句、用户译文、参考译文、评分、错误、润色建议、评价

### E. 历史记录 (History)

- 本地存档： 记录每次练习的日期、原文标题、总用时、AI 评分
- 复盘功能： 点击历史记录可重新查看该次翻译的详细 AI 分析结果
- 删除功能： 支持删除单条历史记录

## 3. 界面设计要求 (UI/UX)

- 风格： 现代简约，使用 Tailwind CSS 和 Shadcn UI
