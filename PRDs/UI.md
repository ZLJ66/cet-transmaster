这份文档整合了之前所有的细节要求，形成了一份标准的、可直接交付给 Cursor 或开发者的 UI 设计规范手册 (Standard UI Design Document)。
------------------------------
CET-TransMaster 完整 UI 设计文档 (V3.0)1. 设计语言与风格 (Design System)

* 核心理念：沉浸式学习、高效交互、专业反馈。
* 色调 (Palette)：
* 主色 (Primary): Slate-900 (导航/标题) / Indigo-600 (动作按钮)
   * 背景 (Background): Gray-50 (全局) / White (卡片)
   * 状态 (Status): Green-600 (正确/完成)、Red-500 (错误)、Amber-500 (警告/计时)
* 字体 (Typography)：
* 中文：PingFang SC, Microsoft YaHei
   * 英文：Inter, Roboto Mono (用于代码或对比区)

------------------------------
2. 页面结构与功能规范 (Page Specifications)2.1 首页 (Dashboard)

* 顶部栏：应用名称、[开始练习] 按钮、[API 设置] 图标。
* 统计卡片：展示“总练习篇数”、“累计时长”、“平均评分”。
* 历史记录列表：
* 条目内容：原文首句摘录、日期、总用时（MM:SS）、得分。
   * 交互：点击条目进入历史分析详情页。

2.2 准备与拆分页 (Setup & Splitter)

* 输入区：左侧原文输入框（Textarea），右侧参考译文输入框（选填）。
* 智能拆分预览：
* 逻辑：根据 。！？\n 自动切分。
   * 交互：
   * 合并：点击两句之间的 ↑ 图标。
      * 拆分：在预览文本中点击鼠标光标位置，点击出现的 [+] 按钮。
      * 编辑：允许直接点击预览句进行文字微调。
   
2.3 翻译练习页 (Training - 核心页)

* 顶部导航：进度条 (current/total)、实时计时器 (MM:SS)。
* 左右布局 (6:4 分栏)：
* 左侧 (原文预览区)：
   * 显示完整段落。
      * 高亮逻辑：当前句深色显示并带有左侧边框高亮；非当前句 opacity-40。
      * 回溯功能：用户点击任意历史句子，右侧输入框自动同步该句内容供修改。
   * 右侧 (翻译输入区)：
   * 原文卡片：展示当前正在翻译的单句中文。
      * 输入框：使用 自适应高度 Textarea，取消内部滚动条。
      * 快捷键：监听 Enter。若非最后一句则跳至下一句；若是最后一句则提交分析。
   * 计时暂停功能：
* 控制：点击 [暂停] 按钮。
   * UI 响应：整个练习区（左/右分栏）应用 backdrop-filter: blur(12px)，并弹出“计时已暂停”浮层，隐藏当前题目内容。

2.4 AI 分析页 (Analysis Report)

* 总览区：综合评分、总用时、AI 总体评语。
* 对照分析区：
* 三行对照布局：[原文] -> [我的译文] -> [参考译文/AI 建议]。
   * 差异高亮：
   * 红色删除线：语法错误或拼写错误。
      * 蓝色加粗：高级替换词汇建议。
   * 容错处理：
* 若某句 AI 生成失败，该句显示 [重新生成] 按钮，不影响整篇显示。

2.5 API 设置页 (Settings)

* 多服务商支持：OpenAI, DeepSeek, Google Gemini, 智谱 AI (Zhipu), Minimax。
* 字段：服务商下拉菜单、API Key 输入框、Base URL (可选)、模型选择 (Model ID)。
* 存储：数据仅持久化于浏览器的 localStorage。

------------------------------
3. 交互行为说明 (Interaction)

   1. 数据持久化：用户每输入一个单词，程序实时将当前的 userTranslations 数组存入 localStorage，防止页面刷新导致进度丢失。
   2. 异常捕获：API 请求设置 30s 超时。若失败，弹出 Toast 提醒：“网络连接超时，请检查 API 配置或重试”。
   3. 转场动画：使用 Framer Motion，在切换句子时，左侧的高亮条平滑滑动，右侧的输入框淡入淡出。

------------------------------
4. 给 Cursor 的组件开发建议

* State 定义 (Zustand):

interface AppState {
  sentences: string[];       // 拆分后的原文
  userDrafts: string[];      // 用户的译文
  status: 'idle' | 'training' | 'paused' | 'analyzing';
  config: { provider: string, apiKey: string, model: string };
}

* 计时器 Hook: 封装一个 useTimer，支持 start, pause, resume, reset。

1. 技术栈选择 (Recommended Tech Stack)
为了让 Cursor 生成高质量、现代化的代码，建议指定以下库：

* 框架: Next.js 14+ (App Router) —— 现代 Web 开发标准。
* 组件库: Shadcn UI (基于 Radix UI) —— 界面美观且代码易于 AI 维护。
* 样式: Tailwind CSS —— 快速布局和响应式设计。
* 状态管理: Zustand —— 轻量级，非常适合处理计时器和 API Key。
* 图标: Lucide React —— 简洁的矢量图标。
* 输入增强: react-textarea-autosize —— 实现输入框高度随内容自动撑开。
